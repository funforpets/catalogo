# Catálogo de atacado FunForPets

Catálogo dos importados (Its Pet e FunForPets) e da indústria (It's Natural e Mordidinhas) com lista de cotação enviada pelo WhatsApp da vendedora.

- `CONTEXTO.md`: tudo o que foi decidido, o que está pendente e como continuar
- `TRACKING.md`: eventos do dataLayer para o GTM/GA4
- `src/`: template da página, lista de produtos, scripts de build e de fotos, testes
- `index.html`: gerado por `python3 src/build.py` (não editar direto)
- `analytics.js`, `img/`, `banners/`, `logo/`: arquivos servidos pelo site
